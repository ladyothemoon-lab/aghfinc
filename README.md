# AGHFINC Repository

Official repository of AGHF Inc. (d/b/a AgroHouse Foundation).

## About AGHF

AgroHouse Foundation is a Florida nonprofit organization focused on community outreach, stabilization, education, and support services.

## Repository Contents

This repository contains organizational records, governance documents, 501(c)(3) formation and compliance documents, program materials, operational resources, strategic planning documents, and other records supporting AgroHouse Foundation's mission and development.

## Current Program

### Community Outreach Stabilization Program

AGHF's flagship program focused on outreach, resource navigation, and stabilization support within the community.
